## 실제로 실행한 명령과 관측

새 폴더의 on-client에서 다음 명령을 실행했습니다.

```powershell
node --version
npm run check
$env:ON_PORT='5199'
npm run demo
```

Node v24.22.1, 문법 검사 종료 코드 0. 서버가 http://127.0.0.1:5199 에서 시작됐습니다. /api/events는 HTTP 200, meta.mode=demo, 예제 사건 event-01을 반환했습니다. 서버를 Ctrl+C로 종료하고 같은 명령으로 다시 실행한 뒤 /api/events의 200과 demo 표시를 재확인했습니다. 이는 예제 자료의 HTTP 응답 재현이며 실제 원천 연결이나 화면 클릭 재현이 아닙니다.

별도 실행:

```powershell
$env:ON_PORT='5200'
npm start
```

http://127.0.0.1:5200 에서 시작됐고 /api/me는 HTTP 503, error.code=ENGINE_NOT_CONNECTED, meta.mode=disconnected였습니다. 개인 원천 연결·AI 자격은 복사하지 않았습니다.

작업용 소스에서 별도로 가상 DOM 27건과 제공 파일 73개의 SHA-256 일치를 확인했습니다. 이는 로컬 개발 검사입니다. 실제 브라우저 UI나 공식 심판을 실행한 검사로 세지 않습니다.

## UNV와 버전 경계

- 브라우저의 메뉴·클릭·화면 초기화·다른 사건 선택 후 지연 응답 거절: 미확인.
- 실제 SDP 계정·기기·세션·접속 판정·XDR 기록 연결: UNV.
- 이번 복사본에서 승인된 실제 AI 사건 설명: UNV.
- 실제 원천 집행기·권한·대상·결과 관측: UNV. ACK를 효과로 간주하지 않습니다.
- 프로젝트 잠금 파일과 승인된 공개 패키지 목록을 이용한 실제 OSV 결과: UNV. 미조회를 취약점 없음으로 쓰지 않습니다.
- 포털 21·22단계는 확인 당시 반 개방 제한이 있었으며 공식 제출·통과는 미확인입니다. 로그인 재개가 필요한 상태입니다.
